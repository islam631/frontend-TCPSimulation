# 🌐 TCP Visualizer Flow

Une application web interactive pour simuler et visualiser le fonctionnement du protocole **TCP (Transmission Control Protocol)** étape par étape.

---

## 📘 Description

Ce projet pédagogique permet de visualiser les différentes étapes de la communication TCP :

- Connexion : 3-Way Handshake (SYN → SYN-ACK → ACK)
- Transfert de données (avec numéros de séquence et ACK)
- Fermeture de la connexion
- (Optionnel) Visualisation du contrôle de flux / congestion

---

## 🚀 Fonctionnalités

- 🔁 Animation du handshake TCP
- 📦 Simulation de l’envoi de paquets avec ACK
- ❌ Gestion de la terminaison de la connexion
- 👀 Interface graphique interactive
- ⚙️ Développement moderne avec Vite + TypeScript


## ⚙️ Technologies utilisées

- TypeScript
- React
- Vite

---


## Installer les dépendances

npm install
